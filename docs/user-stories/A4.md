# A4 — Prompt Versioning

Les prompts sont des artefacts versionnés : chaque version est datée, a un parent et une empreinte, et ne change plus une fois publiée. On choisit la version par configuration (donc on peut revenir en arrière sans toucher au code), et le harness d'évaluation compare deux versions en qualité, latence et tokens.

Chaque critère sera relié à un test ou à un rapport. Tâches : PROMPT-01 (registre), CORE-14 (prompt v2), EVAL-08 (comparaison). Spécification : PROJECT.md §6.11. Contrat : [`docs/contracts/v1.1-extensions.md`](../contracts/v1.1-extensions.md) §3.6. Les tests ci-dessous sont **prévus** (noms indicatifs).

## US-A4-01
En tant que **membre de l'équipe**, je veux **comparer deux versions du prompt sur le golden set**, afin de **n'adopter une modification que si elle améliore réellement la qualité**.

**Critères d'acceptation**
- `sensai eval --prompt-version v1` puis `v2` produisent deux rapports, chacun avec le nom, la version et l'empreinte du prompt utilisé.
  — vérifié par : *à relier* (prévu : `tests/unit/eval/test_harness.py::test_report_records_the_prompt_version`).
- `sensai eval compare` affiche l'écart d'exactitude (EX), de fidélité, de latence et de tokens entre les deux.
  — vérifié par : *à relier* (rapport d'EVAL-08) ; démo : slide « prompt v1 / v2 » de l'acte 6.
- La décision (v2 adoptée, ou v1 conservée faute de gain) est écrite dans `docs/decisions.md` avec les chiffres.
  — vérifié par : `docs/decisions.md`.

**Statut** : à faire (PROMPT-01, CORE-14, EVAL-08)

## US-A4-02
En tant qu'**admin IT**, je veux **revenir à la version précédente du prompt par une ligne de configuration**, afin de **corriger une régression sans modifier ni redéployer le code**.

**Critères d'acceptation**
- `[agent] prompt_version = "v1"` (ou `SENSAI_AGENT_PROMPT_VERSION=v1`) fait tourner l'agent sur la v1 au démarrage suivant ; une version inconnue est refusée au démarrage avec un message clair.
  — vérifié par : *à relier* (prévu : `tests/unit/core/test_prompts.py::test_version_is_chosen_by_config`, `test_unknown_version_is_refused`).
- Une version publiée ne peut pas changer en silence : modifier son fichier sans créer de nouvelle version fait échouer les tests.
  — vérifié par : *à relier* (prévu : `test_prompts.py::test_published_prompts_never_change`).
- `sensai prompts list` et `sensai prompts diff v1 v2` montrent les versions et leurs différences.
  — vérifié par : *à relier* (prévu : `tests/unit/test_cli_entrypoint.py::test_prompts_commands`).

**Statut** : à faire (PROMPT-01)
