# A5 — Persona

Le nom, le ton, le périmètre et les **outils autorisés** de l'agent sont définis par profil, dans des fichiers TOML (`personas/`). Trois profils servent le scénario : Contrôle de gestion (Claire, lecture seule), ADV (Karim, écritures SQL sous confirmation), Admin (Inès, écriture de fichiers sous confirmation). On change de profil en cours de séance sans perdre l'historique. Un profil ne fait que **restreindre** : il ne lève jamais une confirmation.

Chaque critère sera relié à un test ou à une étape de démo (actes 1, 4 et 5 de [`docs/keynote/scenario.md`](../keynote/scenario.md)). Tâches : PERS-01 (moteur), WEB-15 (sélecteur), SEC-02 (escalade). Spécification : PROJECT.md §6.12. Contrat : [`docs/contracts/v1.1-extensions.md`](../contracts/v1.1-extensions.md) §3.1, §3.7, §4. Les tests ci-dessous sont **prévus** (noms indicatifs).

## US-A5-01
En tant que **responsable ADV**, je veux **passer au profil ADV en cours de séance sans perdre la conversation de Claire**, afin d'**enchaîner sur le nettoyage du fichier clients avec tout le contexte**.

**Critères d'acceptation**
- `/persona adv` en CLI ou le sélecteur de la barre d'état change le profil au tour suivant ; la conversation affichée et l'historique envoyé au modèle sont conservés.
  — vérifié par : côté web (WEB-15), `tests/unit/web/test_ws.py::test_set_persona_changes_the_tools_and_keeps_the_padlocks`, `::test_set_persona_is_accepted_during_a_turn` et `web/src/session/reducer.test.ts` (« profile change ») ; côté moteur, *à relier* (prévu : `tests/unit/core/test_personas.py::test_switch_keeps_the_history`, PERS-01) ; démo : acte 4.
- Le changement est visible : badge du profil, séparateur « Profil : ADV (Karim) » dans le fil, message « Profil actif » dans l'historique du modèle.
  — vérifié par : badge et séparateur, y compris après un rechargement, `tests/unit/web/test_ws.py::test_the_profile_change_is_replayed_in_place_after_a_reload` et `reducer.test.ts` (« a reload replays the separator in place ») ; message « Profil actif » de l'historique du modèle, *à relier* (PERS-01).
- Un profil inconnu est refusé (`PERSONA_NOT_FOUND`) sans changer le profil courant.
  — vérifié par : `tests/unit/web/test_ws.py::test_unknown_persona_is_refused`.

**Statut** : partie web faite sur le MockEngine (WEB-15) ; moteur à faire (PERS-01)

## US-A5-02
En tant que **responsable sécurité**, je veux **que le profil Contrôle de gestion ne puisse jamais modifier les données**, afin que **les droits ne dépendent pas de la bonne volonté du modèle**.

**Critères d'acceptation**
- Les outils d'écriture sont absents de la liste présentée au modèle pour ce profil.
  — vérifié par : *à relier* (prévu : `test_personas.py::test_tools_are_filtered`).
- Si le modèle appelle quand même un outil hors profil, la politique le refuse (`TOOL_DENIED`) et rien n'est exécuté.
  — vérifié par : *à relier* (prévu : `tests/unit/tools/test_policy.py::test_tool_outside_the_persona_is_denied`, attaque « escalade de profil » de SEC-02).
- Aucun profil ne lève une confirmation : avec le profil ADV, une purge demande toujours la confirmation.
  — vérifié par : *à relier* (prévu : `test_policy.py::test_a_persona_never_removes_a_confirmation`) ; démo : acte 4.

**Statut** : à faire (PERS-01, SEC-02)

## US-A5-03
En tant qu'**intégratrice**, je veux **créer un nouveau profil en ajoutant un fichier**, afin d'**adapter l'assistant à un autre métier sans toucher au code**.

**Critères d'acceptation**
- Un fichier `personas/<id>.toml` valide (nom, rôle, ton, périmètre, outils) apparaît dans `/personas` et dans le sélecteur au démarrage suivant.
  — vérifié par : *à relier* (prévu : `test_personas.py::test_a_new_file_is_a_new_persona`).
- Un fichier invalide est refusé au démarrage avec un message qui cite le fichier et le champ en cause.
  — vérifié par : *à relier* (prévu : `test_personas.py::test_invalid_file_is_reported`).
- Le ton et le périmètre du profil changent les réponses (un profil refuse poliment une question hors de son périmètre).
  — vérifié par : démo, question hors périmètre posée avec deux profils différents.

**Statut** : à faire (PERS-01)
