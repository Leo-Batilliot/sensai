Légende des pastilles
1Génération · modifiable : les trois réglages que l'utilisateur peut changer depuis le navigateur.
2num_ctx : liste de valeurs (4 096, 8 192, 16 384, 32 768). Avertit que le modèle sera rechargé. La jauge de la barre d'état suit la nouvelle valeur.
3Juge on/off : judge_enabled. Désactivé, le badge est remplacé par la chip « Juge désactivé ».
4Appliquer : envoie set_config {patch: {temperature, num_ctx, judge_enabled}} ; le serveur répond config_updated. Effectif au tour suivant, historique conservé. Réinitialiser envoie un set_config dont le patch est defaults de GET /api/config.
5Lecture seule : liste lue dans GET /api/config (read_only) : hôte Ollama, modèle du juge, keep_alive, garde-fous de l'agent, limites SQL, délai HITL, tolérance numérique. Modifiables seulement dans config.toml.
